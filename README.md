## Master's thesis repository

The data in this repository too heavy to be loaded to github (the current data 
folder weights 197GB).

All the data necessary can be downloaded through the scripts in
the `download_scripts` folder.

The code from data preprocessing to the final results and plots can be
found in the `analysis_scripts_folder`. The scripts here must be run following
the order indicated by the number at the beggining of file names.

The `issue_with_mitms_income` contains an older script that motivated part
of this masters thesis. It shows how the MITMS dataset uses the income variable
from 2020 in all their trips (regardless of the year).
